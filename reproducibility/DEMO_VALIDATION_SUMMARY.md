# VM Module Validation Summary

Validation date: 2026-10-15

A deterministic synthetic smoke-test dataset (80 rows, seed 42) was used to smoke-test the implemented modules. These tests verify software execution; they are **not scientific MOF benchmark results**.

## PASS

- Core 8-model benchmark: LG, RFR, ANN, LSTM, GRU, TFT baseline, CNN_LSTM, MOF_PREDICTIUM all returned results on a 60-row smoke-test dataset.
- Robustness Suite: Isolation Forest, Gaussian augmentation, SMOTER-compatible augmentation, ensemble uncertainty, learning curve and OOD outputs generated.
- Multi-target prediction: 5-fold OOF metrics/predictions and reusable model generated for three tutorial targets.
- Stratified evaluation: subgroup metrics and leave-one-group-out metrics generated for topology, metal node and linker family.
- Batch high-throughput screening: MOF_PREDICTIUM produced ranked predictions, uncertainty dispersion and OOD fields for 240 candidates.
- PCA mapping: coordinates and PNG generated.
- Pareto analysis: completed for three objectives; 13/80 tutorial candidates were non-dominated in the demonstration.
- Inverse-design retrieval: top-20 candidates generated by standardized descriptor-space distance minimization.

## Environment-specific item

UMAP code is implemented and `umap-learn>=0.5` is included in `requirements.txt`. The validation container used for packaging had no network access and did not have `umap-learn` preinstalled, so this environment generated `UMAP_NOT_INSTALLED.txt` while PCA completed. On the normal Windows development machine, running `pip install -r python_scripts/requirements.txt` enables UMAP output.


## MOF-NP round-robin module

The v2.3.0-VM-RR development package was additionally exercised with the deterministic round-robin self-test and a five-file XLSX merge/reanalysis path. The test produced 90 record-level measurements across five pseudonymous laboratories and six matched conditions, preserved file/row provenance, generated metadata-completeness outputs, agreement tables (including ICC where supportable), review flags and PNG plots. These are synthetic software-validation outputs only, not experimental toxicity results.
